# 移光定位 · 花开子午

子午流注纳甲法开穴可视化时钟（单文件 HTML，零依赖，浏览器直接打开）。

## 功能

- 实时显示当前时辰、日干支、时辰干支（五鼠遁）
- 开天门气交推算：十干合化定气交时刻，未过开天门沿用前日之气
- 井荥输经合五穴花瓣，每 24 分钟顺次绽放
- 任意日期时间查询花开（穴位流注）
- 点击花瓣/中心穴名弹出穴位信息卡（归经、定位、主治，66 穴）
- 开穴数据已与《子午流注开穴表》逐格校准

## 关联项目

- 灵感与数据参照：[JICio/tcm-3d](https://github.com/JICio/tcm-3d)（3D 穴位人体教学模拟，MIT / CC BY 4.0）
- 本仓库通过 GitHub Actions 每日监测 tcm-3d 是否有新提交，发现升级会自动开 Issue 提醒同步（见 `.github/workflows/watch-upstream.yml`）
